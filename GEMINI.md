# Chat GPT Clone

A simple ChatGPT clone built with SvelteKit.

## Features
- **Chat Interface**: Clean, responsive UI resembling ChatGPT.
- **API Integration**: Connects directly to OpenAI API (or compatible) using user-provided API Key.
- **Markdown Support**: Renders AI responses with Markdown.
- **Settings**: Local storage persistence for API Key.

## Tech Stack
- **Framework**: SvelteKit (Svelte 5)
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide Svelte
- **Markdown**: Marked

## Setup
1.  Clone repository.
2.  `npm install`
3.  `npm run dev`
4.  Open settings and enter your OpenAI API Key.
